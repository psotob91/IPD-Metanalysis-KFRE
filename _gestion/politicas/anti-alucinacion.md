# Política anti-alucinación

Regla de oro: **no afirmar ni citar nada que no esté verificado.**

1. **Referencias solo verificadas**: cada cita debe tener DOI o PMID confirmado (PubMed/Crossref).
   Verificar autores, año, revista, volumen y páginas contra la fuente, no contra la memoria.
2. **PMID desde memoria = prohibido**: nunca escribir un identificador "de memoria". Buscar y
   confirmar. (En este proyecto varios PMID recordados resultaron ser de otros artículos.)
3. **Si no se verifica, no se numera**: una afirmación sin respaldo verificable se reformula o se
   marca como pendiente en `MEMORIA.md`, no se inventa la cita.
4. **Cifras y resultados**: los números de estudios previos (C-index, O/E, etc.) se copian del
   abstract/artículo, no se estiman.
5. **Separar hecho de inferencia**: si algo es una recomendación general y no una cita puntual,
   redactarlo como tal, sin colgarle una referencia que no lo sustenta.
6. **Verificación final**: antes de entregar, revisar que cada número de cita del texto exista en
   la lista de referencias y apunte al artículo correcto.
